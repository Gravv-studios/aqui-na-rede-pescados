# Aqui na Rede Pescados

Site estático oficial: catálogo de pescados, combos, fotos, vídeos e pedido pelo WhatsApp.

Abra index.html ou sirva a raiz como site estático. Não é necessário instalar dependências.

Esta cópia contém somente os arquivos públicos autorizados. Dados internos, CRM e estoque não são publicados.

Sincronização a partir do projeto de edição local; cada atualização concluída é registrada em Git. Evite editar esta cópia em paralelo sem integrar as mudanças ao projeto de origem.
